## Manufacturing Production Analytics Dashboard

### Project Overview

This project presents an **interactive Production Analytics Dashboard built using Excel** to analyze manufacturing performance, operational efficiency, and production cost distribution across multiple product categories.

The dashboard transforms raw manufacturing data into **actionable business insights** through interactive visualizations and analytical summaries. It allows stakeholders to monitor production performance, evaluate operational workload distribution, and track cost efficiency across different product types.

The project demonstrates how **Excel can be used as a powerful business intelligence and data analysis tool** for operational analytics.


### Business Problem

Manufacturing organizations generate large volumes of production data across various departments, product categories, and operational managers. However, raw data alone does not provide clear insights into production efficiency, cost distribution, or operational performance.

Without proper analysis and visualization, it becomes difficult to:

* Track production trends over time
* Identify cost-intensive product categories
* Evaluate managerial workload distribution
* Monitor operational efficiency

This project addresses these challenges by building an **interactive Excel dashboard that converts raw production data into meaningful and actionable insights.**


### Project Objectives

The primary objectives of this project are:

* Analyze **total production cost by product category**
* Monitor **monthly production output trends**
* Evaluate **task distribution among operational managers**
* Measure **average production cost per unit**
* Enable **interactive analysis using filters and slicers**
* Transform raw operational data into **business intelligence insights**


### Dataset Information

The dataset contains production-related operational data used to analyze manufacturing performance.

**Key attributes** in the dataset include:

| Column          | Description                               |
| --------------- | ----------------------------------------- |
| Product Type    | Category of product manufactured          |
| Production Cost | Total cost associated with production     |
| Units Produced  | Number of units manufactured              |
| Manager         | Operational manager responsible for tasks |
| Production Date | Date of production activity               |
| Region          | Geographic region of operation            |
| Gender          | Employee gender classification            |
| Age Group       | Workforce demographic segmentation        |
| Quarter         | Production quarter for trend analysis     |



### Dashboard Features

The Excel dashboard includes several analytical visualizations:

#### 1. Total Production Cost by Product Type

Analyzes cost distribution across product categories including automobiles, electronics, furniture, and machinery.

#### 2. Monthly Units Produced

Tracks production output trends from **September 2023 to September 2024**, helping identify seasonal patterns and fluctuations.

#### 3. Number of Tasks by Manager

Displays operational workload distribution among managers, highlighting performance and responsibility allocation.

#### 4. Average Production Cost per Unit

Evaluates cost efficiency across product categories.

#### 5. Interactive Filters

The dashboard includes slicers that allow users to filter insights by:

* Region
* Gender
* Age Groups
* Production Quarter
* Production Date

These filters enable **multidimensional analysis of operational performance.**


### Key Insights

The analysis reveals several important operational insights:

**1. High Production Cost Category**

Automobiles represent the highest total production cost among all product categories.

**2. Production Trends**

Monthly production volumes fluctuate significantly, indicating variations in manufacturing output across different periods.

**3. Managerial Workload Distribution**

A small number of managers handle a higher proportion of operational tasks, suggesting potential workload concentration.

**4. Cost Efficiency Differences**

Furniture production shows relatively higher cost per unit compared to other product types.

**5. Interactive Operational Analysis**

The dashboard allows users to dynamically explore production performance using multiple segmentation filters.
